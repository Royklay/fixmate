# FixMate — Find Help. Fix It. Move On.

**Live Link:**https://royklay.github.io/fixmate/

## Overview

FixMate is a service-finding platform that connects customers with nearby professionals who can provide services at the customer's location.

The website helps users find professionals such as electricians, plumbers, mechanics, and other service providers without the difficulty of searching for help on their own.

FixMate also gives professionals an opportunity to reach more customers and grow their businesses.

## Features

- **Home Page:** Introduces FixMate and provides navigation to other pages.
- **Services Page:** Displays the different services available on the platform.
- **E-Providers Page:** Helps users explore available service providers.
- **Profile Page:** Displays a professional's information and services.
- **Sign Up Page:** Provides a registration interface for users.
- **Professional Page:** Displays pricing plans for professionals who want to use the platform.
- **Navigation:** Connects the website pages through links and buttons.

## Design Structure

FixMate follows a clean, modern, and user-friendly design.

- **Layout:** Organized sections and service cards make information easy to find.
- **Color Scheme:** Consistent colors create a professional appearance.
- **Typography:** Clear headings and readable text improve the user experience.
- **Navigation:** Simple links and buttons make moving between pages easier.
- **Responsive Design:** CSS helps the website adapt to different screen sizes.
- **Consistency:** Shared styling maintains a uniform appearance across pages.

## Technologies Used

- HTML5 — Structures the website content.
- CSS3 — Styles the pages, layouts, colors, and elements.
- Tailwind CSS — Used where applicable for utility-based styling.
